# 💻 Operating Systems & Networking Labs

This repository contains practical implementations of core Operating Systems concepts and network communication, developed as part of the OS course at FINKI.

## 🔑 Key Concepts Covered
* **Process Synchronization:** Solving classic synchronization problems using semaphores and monitors.
* **Multithreading:** Implementation of concurrent execution logic in Java.
* **Networking:** Socket programming using **TCP/IP protocols** for client-server communication.
* **System Scripts:** Automation using Bash/Shell scripting (`scr.sh`).

## 📂 Laboratory Exercises
- **OSLab1:** Introduction to shell environments and basic system calls.
- **OSLab2:** Advanced thread synchronization and resource management.
- **OSLab3:** Network programming and building functional TCP Clients.
